# Glossary

| Istilah | Arti |
|---|---|
| Module | Kelompok workflow ber-ID `MOD-XXX`. |
| Menu | Layar dalam module ber-ID `MENU-XXX`. |
| Scenario | Test detail `SCN-MENU-XXX-001`. |
| Fact | Informasi disetujui. |
| Inference | Kesimpulan demo yang perlu review. |
| Unknown | Informasi belum tersedia dan tidak boleh direka. |
| Reference | File/data contoh untuk konteks planning. |
