# Constraints

React, Vite, JavaScript, CSS, Framer Motion, JSZip, pdfjs-dist, browser routing, Vercel serverless function untuk AI proxy. Tanpa auth atau database.

- Upload: drag-and-drop, multi-file, safe whitelist ZIP.
- File maksimal 50 MB; extract ZIP maksimal 100 MB atau 2000 entry.
- AI optional, terenkripsi environment variables, tidak mengekspos API key.
- Tema: terang, gelap, system; dipersist di localStorage key `magnetstructure-theme-v1`.
- Aksesibilitas: semantic action, label form, focus ring, aria-live, reduced motion.
- Layout usable pada 1440px, 1024px, dan 375px.
