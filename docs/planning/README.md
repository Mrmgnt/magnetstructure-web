# Paket Planning Magnetstructure Web

Planning Phase 1 untuk workflow referensi → discovery → pertanyaan → struktur → preview → generate → ZIP.

- `project/`: visi, scope, istilah, constraint, discovery.
- `architecture/`: system, module, data, integration, security.
- `standards/`: kontrak frontend, future backend, permission.
- `modules/`: overview dan test plan per module/menu.
- `testing/`: strategi, katalog, baseline, scenario detail.

Keputusan: frontend-only, local state, tanpa backend/auth/database/API AI. Unknown tetap eksplisit.
